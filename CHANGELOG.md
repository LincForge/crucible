## [0.2.0] - 2026-10-24

First public release. 0.1.0 below is the internal baseline it grew from; it was never published.

### Added
- MCP Tools (8): adds `crucible_bvt` and `crucible_usage_stats` (6 at the time of the 0.1.0 baseline).
- Apache-2.0 `LICENSE`, `NOTICE`, `SECURITY.md`, and `CONTRIBUTING.md` for the `LincForge/crucible` release mirror.
- `crucible fuelcheck --json`: the probe results as a JSON list of `{"name", "status", "detail"}` objects.
- `linc_crucible.config_contract.ENV_VARS`: every environment variable crucible reads, in one table, rendered into the README "Configuration" section and pinned to the code by a test.

### Changed
- Stranger-run README and CLI/preflight/deployer fixes (R6): `README.md` now states the Python 3.13+ prerequisite (`--python 3.13` with pipx/uv) in `## Install`, places `## Project setup` (documenting project-root `./gradlew` execution, the unmeasured-assay exit `1` contract, and `<project>/store/store-listing.md` + `<project>/store/brand-brief.json` with required fields) before `## Quickstart`, clarifies `crucible_baseline`'s CLI surface (`crucible baseline capture|list|prune` vs MCP-only `a11y` mode and `latest`/`promote`), and matches the shared `NERVE_UNREACHABLE_MSG` constant in `## Troubleshooting`; `preflight._probe_docs_dir` checks `<project>/store/` before the legacy `$LINC_WORKSPACE` layout and drops the hardcoded `slug_map`; `fuelcheck` and `config_contract.ENV_VARS` document `<project>/store/` and the `~/projects/LINC` fallback when `LINC_HOME` is unset; `Deployer` surfaces `NERVE_UNREACHABLE_MSG` when nerve discovery is unreachable; and `crucible fleet discover|add|remove` and `crucible baseline capture|prune` now route through `linc_cli_kit.emit` so stdout is JSON by default and Rich text under `--human` with exit codes preserved.
- `crucible_pour` `launch_intent` now passes deep-link URIs (e.g. `myapp://settings`) through `NerveClient.launch(..., uri=...)` to `nerve_launch` and refuses activity-form or non-URI values (such as `.MainActivity` or `com.example/.MainActivity`) before any build with `validation_error: True` (`error_category: "validation"`, CLI exit 2) instead of silently ignoring them; `ForgeProject` now reads `identity.package` and `identity.bundle_id` from `linc-manifest.yaml` (resolving Android package as badged APK → `identity.package` → Gradle source → none and iOS bundle ID as `identity.bundle_id` → `project.yml`/`pbxproj` → none), and the private `com.lincmobile.<name>` fallback has been removed so unresolvable app identities fail clearly with a hint to set `identity.package` or `identity.bundle_id` in `linc-manifest.yaml`.
- `AssayReport.to_dict()` now emits `"pass_rate": None` when `tests.score_input is None` (instead of a vacuous `1.0`) and adds top-level `"measured": bool` and `"status"` in `{"measured", "partial", "unmeasured"}`; at the CLI boundary (`_local_fn`), an unmeasured assay exits `1` with error code `UNMEASURED` (`status: "partial"` stays exit `0` with `ship_gate: false`), a `crucible bvt` run with `ran: false` exits `1` with `code=<REASON>` and mapped category (`not_found` for `unknown-project`/`suite-dir-missing`, `permission` for `personal_device`, `unavailable` for `device-reserved`/`device-not-ready`/`nerve-daemon-unreachable`, `internal` otherwise), and tool errors carrying `error_category` in `{"not_found", "personal_device", "validation"}` map to CLI error categories `"not_found"`, `"permission"`, and `"validation"` (exit `2` for `"validation"`, `1` otherwise) (R4 Low 12).
- `crucible fuelcheck` reports one `ok`/`warn`/`skip`/`fail` line per probe (install, tools, LINC workspace, projects, fleet registry, device policy, MCP client config, nerve daemon, MobSF). A missing LINC workspace, nerve daemon, docker or config file is `warn`/`skip` with a one-line hint; a missing personal-device registry is `warn` (no personal devices registered, hint `LINC_DEVICE_FLEET_FILE`) and one that exists but cannot be read is `fail`; it exits 1 only on a broken install or a present-but-unparsable config file. Paths under the home directory are rendered as `~` on stdout and in the warnings crucible logs to stderr while the probes run, so the output is safe to paste into a public issue. The fleet registry (1 MiB) and `~/.claude.json` (16 MiB) are read with a size cap; a larger file is reported with its size and the cap instead of being parsed.
- `README.md` rewritten for an outside user: install (incl. the `linc-ai` fallback note), a fenced quickstart starting with `crucible fuelcheck`, which tools need the nerve daemon, an environment-variable and state-path table under `$LINC_HOME/crucible`, a Trust section (no telemetry; local usage log, `CRUCIBLE_USAGE_LOG`), and the release-mirror note. All links are absolute.
- The architecture overview now states the live tool count (8) and maps `bvt` and `usage_stats`; the README, architecture overview and this changelog are pinned to the MCP registry tool count by tests.
- Package metadata in `pyproject.toml`: `license = "Apache-2.0"`, `license-files = ["LICENSE", "NOTICE"]`, `authors = [{name = "LINC Innovations"}]`, stranger-facing `description`, and `project.urls` (`Homepage`, `Repository`, `Changelog`, `Security`) pointing at `https://github.com/LincForge/crucible`.
- `DevicePolicy` now uses a three-state `state` (`"loaded"`, `"absent"`, `"unreadable"`, retaining a source-compatible `loaded` property): a missing fleet registry fails open (`state="absent"`, `is_personal()` `False`, `refusal()` `None`) with a single `device_fleet_absent` warning per process, while a fleet path entry that exists but is not a readable regular file (dangling symlink, symlink loop, directory, permission denied) or a malformed registry continues to fail closed (`state="unreadable"`).
- The personal-device registry now defaults to the neutral `$LINC_HOME/device-fleet.yaml` (`~/.linc/device-fleet.yaml`) instead of a path inside a private LINC checkout; `LINC_DEVICE_FLEET_FILE` still overrides it. Deployments that keep the registry elsewhere must set `LINC_DEVICE_FLEET_FILE` to keep their personal devices protected.
- Moved `linc-ai` from core dependencies to the private `dev` extra (the public package advertises no `ai` extra); `rank_frames` explicitly guards `linc_ai` imports via `_ai_available()`, restricts built-in CLI tools to `tools=["Read"]` with an accurate permission comment, and falls back to evenly-spaced frame selection with an `asset_ai_unavailable` warning noting that `linc-ai` is not published when the package is absent.
- Removed `opencv-python-headless` from core dependencies: `asset_extractor.filter_frames` now loads frames with Pillow (`Image.open(...).convert("RGB")`) and computes the 3x3 reflect-padded Laplacian blur variance in NumPy (`_laplacian_variance`), eliminating the duplicate `libavdevice` (`AVFFrameReceiver` / `AVFAudioReceiver`) Objective-C class warning on macOS.
- `ForgeProjectReader` now keeps `linc-manifest.yaml` auto-discovery enabled when `FORGE_PROJECTS_FILE` is set (only an explicit `registry_path` constructor argument disables auto-discovery), so manifests on disk continue to be discovered and take precedence on a name clash; replaced private app names and internal tracker references across shipped `src/` docstrings and comments with generic examples (`"myapp"`).

### Security
- `FleetRegistry.discover()` (`crucible fleet discover`) now filters `nerve.discover()` through `DevicePolicy` (`_device_is_personal` across `serial`, `id`, and `hardware_id`) so personal device serials are never persisted to `$LINC_HOME/crucible/fleet.yaml`, fails closed without writing when the policy is unreadable (`fleet_discover_policy_unreadable`), and prints `"skipped N personal device(s)"` (without serials) on the CLI; `SECURITY.md` and `README.md` (`## Trust`) now state explicitly that a project command invoking a shell (`sh -c '…'`, `bash script.sh`) runs a shell as the local user and that the loopback nerve daemon is a trusted peer.
- Anchor simulator UDID, BVT duration, and element bounds regex validators with `\A…\Z` and `re.fullmatch`, and `shlex.quote` Xcode workspace, project, scheme, and destination tokens before command assembly.
- Documented the `.forge.yaml` / `linc-manifest.yaml` project-under-test trust boundary, `safe_subprocess_run` (`shell=False`, metacharacter denylist, process-group timeout termination), and `CRUCIBLE_USAGE_LOG` (`off|redacted|full`, default `redacted`, file mode `0600`) in `SECURITY.md`.
- The MCP usage log (`$LINC_HOME/mcp-calls.jsonl`) is now **redacted by default**: `CRUCIBLE_USAGE_LOG=redacted` (default, and any unknown value) replaces device serials (`device`, `device_serial`, `serial`, `udid`, `devices`), host paths (`project_dir` and any key ending in `_path`/`_dir`/`file`/`video`) and credentials (`api_key`, `token`, `secret`, `password`) with length-only `<redacted len=N>` placeholders and scrubs them from `error`; `off` writes nothing and creates no directory; `full` restores the previous raw-parameter behaviour. The log is created `0600`, opened with `O_NOFOLLOW` (a symlink at the log path is refused), and an older world-readable log is tightened to `0600` on the next write (REVIEW B8).
- Baseline, a11y-baseline, `.compare` and score stores: `project` and `screen_name` must match `[A-Za-z0-9][A-Za-z0-9._-]{0,127}` (no absolute paths, `..`, leading `.`/`-`, whitespace, NUL or separators), and every read, write and prune is proven to resolve inside its store — a symlinked `<store>/<project>` is refused, and prune skips (with a `*_prune_skipped_symlink` warning) a symlinked timestamp or screen dir instead of following it. Previously `crucible_baseline action=prune` with an absolute `project` deleted timestamp dirs outside the store and `action=capture` with a parent-directory `project` wrote outside it. `crucible_baseline` (screenshot and a11y modes) and `crucible_score` return `{"error", "error_category": "validation", "validation_error": true}` for a refused name; `crucible baseline capture|list|prune` exit 2 with a validation envelope on stderr; a BVT visual compare records `verdict: "ERROR"` for such a screen. Store layout is unchanged for valid names.
- Redacted usage-log `error` text also scrubs the home, `LINC_HOME` and `LINC_PROJECTS_DIR` roots (stdlib `OSError` messages embed derived paths); `CRUCIBLE_RUN_ID`/`FORGE_RUN_ID` outside `[A-Za-z0-9._-]{1,128}` is logged as `manual`; a usage-log write failure (`ELOOP`/`EACCES`/`ENOSPC`) is counted and skipped instead of failing the tool call or masking its real exception (REVIEW B8).
- Inverted `CRUCIBLE_USAGE_LOG=redacted` from a denylist to an explicit allowlist (`_UNREDACTED_KEYS`) so every non-allowlisted or newly added tool parameter (including `device_info`, `suite_dir`, `output_dir`, `image_path`, `app_path`, `launch_intent`, `tags`, `exclude_tags`, `server_filter`, and `source_score`) is replaced length-only (`<redacted len=N>`); scrubbed remaining POSIX and Windows absolute path tokens in redacted `error` text to `<path>`; normalised `NaN`/`Infinity`/`-Infinity` floats to `"NaN"`/`"Infinity"`/`"-Infinity"` before `json.dumps(..., allow_nan=False)` so every usage-log line is strict JSON; and created new `LINC_HOME` and crucible state directories with mode `0700` via `ensure_private_dir` while preserving permissions on pre-existing directories.
- `crucible_assay(a11y_tree=True)` now gates its live-device UI tree capture through `DevicePolicy` (new `allow_personal: bool = False` parameter; explicit personal serials and unreadable registries fail closed with `a11y_tree.error_category == "personal_device"` and `attempted_unmeasured == False` before any `elements_strict` call, and auto-pick selects the first non-personal online device). `DevicePolicy` serial matching is now case-insensitive and whitespace-trimmed (`str(serial).strip().casefold()`), and explicit device targets across `pour`, `bvt`, `a11y` baseline capture, and `assay` are resolved against `nerve.discover()` across `serial`, `id`, and `hardware_id` so alias serials (e.g. Wi-Fi ADB `ip:port`) carrying a personal `hardware_id` are refused before any build, install, run, or element read (falling back to the string-only check when the nerve daemon is unreachable).
- Validate all MCP/CLI tool arguments before execution (R4 Medium 5, Low 11): allowlist `build_type` to `\A[A-Za-z][A-Za-z0-9]{0,31}\Z` in both `crucible_pour` and `Deployer._module_scoped_android_build_command` so hostile strings (e.g. `debug --init-script x`) return `validation_error: True` (CLI exit 2) with zero subprocess calls; enforce string length/NUL bounds, relative-path checks on `suite_dir`, strict boolean/integer type checks, and finite numeric range caps across all 8 tools (`max_assets` `1..50`, `top_n` `1..1000`, `limit` `1..1000`, `keep` `0..1000`, `since_hours` `0.0..87600.0` finite); and guard `.forge.yaml` command fields (`test_command`, `lint_command`, `build_command`, `ios_build_command`) against non-string values (`forge_yaml_command_not_string` warning + `config_errors`) and unbalanced quotes (`CommandParseError`) so malformed `.forge.yaml` commands report clean unmeasured/build-error reasons instead of raising.
- Device registries (`load_device_policy` and `FleetRegistry._load`) are now read through `read_capped(..., _MAX_REGISTRY_BYTES)` (shared 1 MiB cap in `_bounded_read.py`), `load_device_policy` parses YAML with a bounded `SafeLoader` subclass that rejects recursive aliases, >100 alias events, or >100,000 expanded nodes before construction, and `_extract_personal_serials` walks iteratively with a `visited` set and a 100,000-node budget so oversized, deeply nested, recursive, or alias-bomb registries fail closed as `state="unreadable"` (`"is too large"` when oversized) instead of raising `RecursionError` or exhausting memory.
- `NerveClient` and `Assayer._run_security` (MobSF upload/scan/report) now construct `httpx.Client(trust_env=False)` instead of reading ambient `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` environment variables or calling module-level `httpx.post`, preventing proxy settings from routing loopback nerve (`:8111`) traffic or the MobSF `Authorization` API key header off-host; pinned across `src/` by an AST contract test.

### Deprecated
- `FORGE_RUN_ID` as the usage-log `session_id` source — set `CRUCIBLE_RUN_ID` instead (it takes precedence). The `FORGE_RUN_ID` fallback will be removed in the next release.

## [0.1.0] - 2026-04-19 (Documented baseline)

### Current State

#### MCP Tools (6 at the time)
- `crucible_pour` — Build, install, launch. Android (Gradle) + iOS (xcodebuild), multi-target routing
- `crucible_assay` — Quality analysis: lint, tests, security, perf, a11y (static + live tree BVT)
- `crucible_score` — Weighted composite quality score (0-100, 7 dimensions, ship gate 85)
- `crucible_preflight` — App store readiness (5 dimensions, 80% threshold)
- `crucible_baseline` — Golden screenshot + a11y tree baselines (capture, list, prune)
- `crucible_extract_assets` — Video-to-screenshot pipeline (blur + pHash dedup)

#### Quality Engine
- QualityScorer with dynamic weight normalization across 7 dimensions
- Visual regression via SSIM (0.95 excellent, 0.70 poor)
- A11y tree BVT: TreeCapture + TreeDiffer (5-level penalty) + WCAGRuleChecker (6 rules)
- Platform-aware touch target thresholds (48dp Android, 44pt iOS)

#### Architecture
- Zero device code — all I/O through NerveClient HTTP at localhost:8111
- Read-only forge integration (linc-manifest.yaml + projects.yaml)
- CLI via Click with Rich formatting
- JSONL observability logging (10MB rotation)
- 558+ tests
